# 🤖 AI Chat Bot с поддержкой множества LLM моделей

Современный веб-чат с поддержкой различных языковых моделей, красивым интерфейсом и возможностью подключения собственных API ключей.

## ✨ Основные возможности

### 🎯 **Меню выбора моделей с рулеткой**
- **Красивые анимации** появления каждого элемента
- **Меню поднимается вверх** вместо стандартного выпадающего
- **Показывает только 7 моделей** по умолчанию с возможностью показать больше
- **Эффект рулетки** с задержкой для каждого элемента
- **Фильтрация по провайдерам** и поиск по названию

### 🔑 **Управление API ключами для каждой модели**
- **Кнопка "Добавить API ключ"** для каждой модели
- **Модальное окно** для ввода и управления API ключами
- **Автоматическая инициализация** DeepSeek API ключа
- **Безопасное хранение** в localStorage браузера
- **Валидация формата** API ключей

### 🚀 **Поддерживаемые провайдеры**

#### **DeepSeek** ✅ (работает из коробки)
- DeepSeek Chat (32K контекст)
- Автоматически подключен при первом запуске

#### **OpenAI** 🔑 (требует API ключ)
- GPT-4o (128K контекст)
- GPT-4o Mini (128K контекст)
- GPT-3.5 Turbo (16K контекст)

#### **Anthropic** 🔑 (требует API ключ)
- Claude 3.5 Sonnet (200K контекст)
- Claude 3 Haiku (200K контекст)

#### **Google** 🔑 (требует API ключ)
- Gemini 1.5 Pro (1M контекст)
- Gemini 1.5 Flash (1M контекст)

#### **Ollama** 🦙 (локальные модели)
- Llama 3.1 70B (8K контекст)
- Llama 3.1 8B (8K контекст)

#### **Qwen** 🔑 (требует API ключ)
- Qwen 2.5 72B (32K контекст)
- Qwen 2.5 7B (32K контекст)

## 🔑 Как подключить API ключи

### **DeepSeek (автоматически)**
- Модель уже подключена и готова к использованию

### **Другие модели**
1. **Откройте меню выбора моделей** (над полем ввода)
2. **Нажмите кнопку "Добавить"** рядом с нужной моделью
3. **Введите ваш API ключ** в модальном окне
4. **Нажмите "Сохранить"**
5. **Модель станет доступной** для использования

### **Формат API ключей**
- **OpenAI/DeepSeek/Google/Qwen**: `sk-...`
- **Anthropic**: `sk-ant-...`
- **Ollama**: не требуется

## 🎨 Особенности интерфейса

### **Статус моделей**
- 🟢 **"API подключен"** - модель готова к использованию
- 🔴 **"Подключите свой API ключ"** - требует API ключ
- ⚫ **Отключено** - временно недоступно

### **Анимации и эффекты**
- **slideUp/slideDown** - появление/исчезновение меню
- **rouletteSpin** - эффект рулетки для элементов
- **starPulse** - пульсирующая звездочка выбора
- **Hover эффекты** - масштабирование, тени, поворот

### **Адаптивность**
- Меню адаптируется под размер экрана
- Прокрутка для длинных списков
- Мобильно-дружественный интерфейс

src/

## 🔒 Безопасность

- **API ключи хранятся локально** в браузере пользователя
- **Никогда не передаются** на сервер (кроме API запросов)
- **Валидация формата** API ключей
- **Автоматическое определение** провайдера по ID модели
