# AI Chat - Веб-интерфейс для чата с DeepSeek

Веб-приложение для чата с AI моделью DeepSeek с поддержкой потокового ответа, сохранением истории и рендерингом Markdown/LaTeX.

## ✨ Особенности

- 🔄 **Потоковые ответы** - ответы ИИ отображаются в реальном времени
- 📚 **Сохранение истории** - автоматическое сохранение в формате JSONL
- 🎨 **Рендеринг Markdown** - поддержка форматирования, кода и LaTeX формул
- ⚡ **Умное управление контекстом** - автоматическое обрезание при превышении лимита токенов
- 🛑 **Кнопка "Стоп"** - прерывание генерации ответа
- 📱 **Адаптивный дизайн** - работает на всех устройствах

## 🚀 Быстрый старт

### 1. Клонирование и настройка

```bash
# Скачайте проект и перейдите в папку
cd "ai chat"

# Создайте файл .env на основе примера
copy .env.example .env
```

### 2. Настройка API ключа

Отредактируйте файл `.env` и укажите ваш API ключ DeepSeek:
```env
DEEPSEEK_API_KEY=your_deepseek_api_key_here
CORS_ORIGINS=http://localhost:3000,http://127.0.0.1:3000
```

### 3. Запуск Backend (FastAPI)

Откройте первый терминал:
```powershell
# Установка Python зависимостей
python -m pip install fastapi uvicorn python-dotenv httpx pydantic python-multipart tiktoken

# Запуск сервера
python -m uvicorn backend.main:app --reload --host 0.0.0.0 --port 8000
```

Backend будет доступен на: http://localhost:8000

### 4. Запуск Frontend (React + Vite)

Откройте второй терминал:
```powershell
cd frontend

# Установка зависимостей (только при первом запуске)
npm install

# Запуск dev сервера
npx vite --port 3000
```

Frontend будет доступен на: http://localhost:3000

## 📖 Использование

1. Откройте http://localhost:3000 в браузере
2. Введите сообщение в поле ввода
3. Нажмите "Отправить" или клавишу Enter
4. Наблюдайте за потоковым ответом от ИИ
5. Используйте кнопку "Стоп" для прерывания генерации

## 🔧 Конфигурация

### Backend (data/config.json)
```json
{
  "provider": "deepseek",
  "model": "deepseek-chat",
  "generation": {
    "temperature": 0.7,
    "max_tokens": 2048
  },
  "api_key_env": "DEEPSEEK_API_KEY"
}
```

### История чата (data/history.jsonl)
Каждая строка - одно сообщение в JSON формате:
```json
{"id": "uuid", "role": "user", "content": "Привет!", "timestamp": "2025-08-17T12:00:00", "meta": {}}
{"id": "uuid", "role": "assistant", "content": "Здравствуйте!", "timestamp": "2025-08-17T12:00:01", "meta": {"tokens_in": 10, "tokens_out": 15}}
```

## 🛠 API Endpoints

- `POST /chat/send` - Отправка сообщения (возвращает Server-Sent Events)
- `GET /history` - Получение истории чата
- `GET /health` - Проверка состояния сервера

## 🤝 Критерии приемки

✅ **Базовый диалог**
- Отправка сообщения и получение потокового ответа
- Сохранение истории после каждого сообщения

✅ **Рендеринг контента**

- LaTeX формулы (MathJax/KaTeX)
- Подсветка синтаксиса

✅ **Потоковая передача**
- Server-Sent Events для реального времени
- Кнопка "Стоп" для прерывания
