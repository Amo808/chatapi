🎯 ДЕМО СЦЕНАРИЙ:

2. Показать чистый интерфейс (только чат)
3. Написать сообщение → показать стриминг
4. Нажать на микрофон → голосовой ввод
5. Показать историю сообщений
6. Открыть настройки (показать минимум опций)

🔧 ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ:

1. Перезапустить бэкэнд:
   python -m uvicorn backend.main:app --reload --host 0.0.0.0 --port 8000

2. Перезапустить фронтэнд:
   cd frontend && npm run dev

3. Проверить файлы:
   - backend/.env (DeepSeek API ключ)
   - frontend/.env.local (API URLs)
